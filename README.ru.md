# dsh-r7-office (Плагин Р7-Офис для DeepSeek Harness & MCP Server)

[![CI](https://github.com/deepseek-ai/dsh-r7-office/actions/workflows/ci.yml/badge.svg)](https://github.com/deepseek-ai/dsh-r7-office/actions/workflows/ci.yml)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](https://opensource.org/licenses/MIT)
[![Node.js](https://img.shields.io/badge/node-%3E%3D20.0.0-brightgreen.svg)](https://nodejs.org/)

**Плагин Р7-Офис и сервер Model Context Protocol (MCP) для DeepSeek Harness.**

Позволяет ИИ-агентам программно анализировать, читать, создавать, редактировать, форматировать и конвертировать документы `DOCX`, `XLSX`, `PPTX` и `PDF` с использованием нативных механизмов Р7-Офис без эмуляции клавиатуры и мыши.

---

## Основные возможности

- **Сохранение исходного форматирования**: контекстная замена и редактирование текста с точным сохранением стилей, шрифтов, цветов, иерархии нумерации и структуры документа.
- **Полная поддержка офисных форматов**:
  - **DOCX**: заголовки, параграфы, списки, таблицы, границы/заливки ячеек, разрывы страниц, метаданные.
  - **XLSX**: листы, диапазоны ячеек (`A1:D10`), числа, строки, расчет и добавление формул (`SUM`, финансовые, математические).
  - **PPTX**: слайды, заголовки, текстовые блоки, фигуры.
  - **PDF**: 100% точная конвертация документов в PDF с использованием локального движка `x2t` Р7-Офис.
- **Безопасность и валидация**: встроенный инструмент `r7_validate` проверяет целостность структуры и XML-схем до и после внесения изменений.
- **Два режима работы**:
  - **Плагин DeepSeek Harness**: прямая регистрация инструментов `r7_*` в `ctx.tools` с инструкциями для агента.
  - **Автономный MCP Сервер**: стандартный протокол JSON-RPC 2.0 (stdio) для подключения к Claude Code, Cursor, Windsurf и любым MCP-клиентам.
- **Мост к открытому окну Р7 Desktop (Этап 2)**: локальный WebSocket-мост для взаимодействия с открытым документом в Р7-Офис (чтение/замена выделенного фрагмента, выполнение скриптов Документ Конструктора).

## Архитектура

```text
DeepSeek Harness → Плагин dsh-r7-office → MCP Server → Ядро Р7 и x2t → DOCX/XLSX/PPTX/PDF
                                                   └─→ Desktop Bridge ──→ Открытое окно Р7 Desktop
```

Подробное описание архитектуры см. в [docs/architecture.md](docs/architecture.md), а архитектурные решения — в [docs/decisions/](docs/decisions/).

## Установка

### 1. Как плагин DeepSeek Harness

Добавьте `dsh-r7-office` в ваш файл `cordis.patch.yml`:

```yaml
- insert:
    - id: r7-office
      name: 'dsh-r7-office'
```

Либо установите через менеджер плагинов Harness:

```bash
dsh plugin install dsh-r7-office
```

### 2. Как автономный MCP Server

Добавьте конфигурацию в ваш MCP-клиент (например, `claude_desktop_config.json` или `.cursor/mcp.json`):

```json
{
  "mcpServers": {
    "r7-office": {
      "command": "node",
      "args": ["/путь/к/dsh-r7-office/src/mcp/cli.js"]
    }
  }
}
```

## Справочник MCP-инструментов

| Инструмент | Описание |
|---|---|
| `r7_inspect` | Анализ структуры документа, оглавления, заголовков, таблиц, листов и слайдов |
| `r7_read` | Чтение структурированных параграфов, markdown-представления или диапазонов данных |
| `r7_create` | Создание новых файлов DOCX/XLSX/PPTX на основе нативных шаблонов Р7 |
| `r7_edit` | Точечное изменение текста/стиля или удаление параграфа в DOCX |
| `r7_replace` | Поиск и замена текста в DOCX с сохранением существующего оформления |
| `r7_insert` | Вставка параграфов, заголовков, списков или разрывов страниц |
| `r7_table` | Создание, чтение, модификация таблиц и ячеек |
| `r7_sheet_read` | Чтение значений и формул из листов XLSX |
| `r7_sheet_write` | Запись значений или 2D матрицы данных в лист XLSX |
| `r7_sheet_formula` | Вставка и расчет формул в ячейках таблицы |
| `r7_slide_create` | Добавление новых слайдов в презентацию PPTX |
| `r7_slide_edit` | Изменение заголовков и текста блоков на слайдах PPTX |
| `r7_convert` | Конвертация документов в PDF, HTML, TXT, DOCX через движок `x2t` Р7 |
| `r7_validate` | Проверка целостности файла и отсутствия повреждений |
| `r7_desktop_status` | Проверка статуса соединения с запущенным окном Р7 Desktop |
| `r7_desktop_selection`| Чтение или замена текущего выделения в открытом окне Р7 Desktop |
| `r7_desktop_exec` | Выполнение команд DocScript / DocumentBuilder в активном редакторе Р7 |

## Пользовательский сценарий работы

Пользователь пишет агенту:
> «Возьми `Отчет.docx`, обнови раздел 3, сохрани оформление, добавь таблицу со сроками и сохрани новую версию в PDF».

Агент выполняет цепочку:
1. `r7_inspect` → анализирует разделы и структуру документа;
2. `r7_read` → считывает исходный текст раздела 3;
3. `r7_replace` → заменяет текст раздела с полным сохранением шрифта и стилей;
4. `r7_table` → добавляет таблицу в конец раздела;
5. `r7_validate` → проверяет отсутствие ошибок в итоговом файле;
6. `r7_convert` → формирует готовый PDF через конвертер Р7.
