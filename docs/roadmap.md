# Project Roadmap

## Phase 1: Core File Processing & MCP Tools (v0.1.0) - Current
- [x] R7-Office environment detection and `x2t` adapter
- [ ] Direct OOXML manipulation engine (DOCX, XLSX, PPTX)
- [ ] Safe text replacement preserving formatting and styles
- [ ] Table inspection and modification
- [ ] Spreadsheet reading, writing, and formulas
- [ ] Slide creation and text frame edits
- [ ] Native PDF conversion via `x2t`
- [ ] Automated validation and integrity checks
- [ ] Full MCP tools suite (`r7_*`)
- [ ] Cordis plugin integration for DeepSeek Harness

## Phase 2: R7 Desktop Live Bridge (v0.2.0)
- [ ] R7 Desktop SDK plugin (`desktop-bridge`)
- [ ] Local WebSocket communication between MCP server and R7 Desktop
- [ ] Real-time document inspection in active editor window
- [ ] Selection manipulation (read/replace selected text/table)
- [ ] DocumentBuilder script execution in live editor session

## Phase 3: Advanced Capabilities & Cross-Platform (v0.3.0)
- [ ] Linux (Debian, RPM, Astra, ALT, RED OS) R7 path auto-discovery
- [ ] macOS R7 Desktop support
- [ ] Advanced chart creation and styling
- [ ] Digital signatures and protection options
- [ ] DeepSeek Harness Web UI preview extension
